  ppu-chipmark-light.svg  for light backgrounds

Pure vector, pixel-grid aligned (shape-rendering: crispEdges). Scales to any
size — use whole-number scale multiples for the crispest pixels.
The die face is a real, scannable QR code to https://ppu.toys.
